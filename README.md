## 🖥️ Amazon EC2

Amazon EC2 (Elastic Compute Cloud) provides virtual servers called **instances** that can be used to run applications and workloads in the cloud.

## 🌍 AWS Regions & Availability Zones

**Regions** are geographical areas where AWS operates its infrastructure.

**Availability Zones** are isolated locations within an AWS Region that help improve application availability and resilience.

## 🚀 EC2 Instance Launch

The basic process includes:

1. Select an AMI
2. Choose an instance type
3. Configure the instance
4. Configure storage
5. Configure security settings
6. Review the configuration
7. Launch the instance
