# AWS EC2 Learning

This file contains my learning notes on Amazon EC2 and basic AWS cloud concepts.

## ☁️ What is AWS?

Amazon Web Services (AWS) is a cloud computing platform that provides services for computing, storage, databases, networking, security, and more.

## 🖥️ What is Amazon EC2?

Amazon Elastic Compute Cloud (EC2) provides virtual servers, called instances, that can be used to run applications and workloads in the cloud.

## 🌍 AWS Regions

An AWS Region is a geographical area where AWS has multiple data centers.

Regions help users deploy applications closer to their users and choose an appropriate location for their workloads.

## 🏢 Availability Zones

Availability Zones (AZs) are isolated locations within an AWS Region.

Using multiple Availability Zones can help improve application availability and resilience.

## 🚀 EC2 Instance Launch — Basic Process

1. Sign in to the AWS Management Console.
2. Open the EC2 service.
3. Choose an Amazon Machine Image (AMI).
4. Select an instance type.
5. Configure the required settings.
6. Configure storage.
7. Configure security settings.
8. Review the configuration.
9. Launch the instance.
